# Using winston logger in NextJS 14
## steps

```
git clone https://github.com/liara-cloud/nextjs-getting-started.git
```
```
cd nextjs-getting-started
```
```
git checkout logger
```
```
npm i
```
```
npm run dev 
```
- for example, check `localhost:3000/api/hello`
